# 企业模型服务配置

管理端打开“AI 课堂服务”，在“模型服务配置”填写兼容 OpenAI Chat Completions 的 API 基础地址、模型 ID 和密钥。基础地址一般包含 `/v1`，服务端追加 `/chat/completions`。此适配器暂不支持仅提供 Anthropic 原生 Messages 协议等不兼容接口的服务。

保存后点击“验证已保存配置”，会向供应商发送一次实际模型请求，可能产生少量费用。仅保存配置不会调用模型。连接验证成功表示文本模型接口可用，不表示整个 OpenMAIC 制课或课堂功能已经接入。

## 权限与存储

- 只有当前企业的企业管理员可以读取配置状态、更新和验证连接，内容作者和学员不能读取密钥。
- 返回数据仅含地址、模型、是否存在密钥和更新时间。密钥通过 AES-256-GCM 加密，企业 ID 作为附加认证数据，存入 `ai_provider_settings`。
- 留空密钥保留已有密钥；更换服务地址必须重新填密钥，避免把原供应商密钥发给新地址。
- 本地开发首次保存时在 `DATA_DIR/ai-encryption-key` 创建随机主密钥，需与数据库一起备份。删除主密钥后不能恢复原有模型密钥，须重新配置。
- 生产环境保存前必须设置稳定的 `AI_CONFIG_ENCRYPTION_KEY`（64 个十六进制字符）。更换主密钥前需要专门的轮换迁移，不能直接覆盖环境变量。
- 生产模型端点必须 HTTPS，解析为公网地址；请求固定解析结果，不跟随重定向。开发环境允许本机模型服务。

## 当前边界

本配置由本地 OpenMAIC 制课适配器使用，管理端支持资料解析、大纲审阅、逐场景生成、人工编辑、预览和草稿应用；发布版本由PC/H5共享播放器学习。旧“OpenMAIC 桥接服务”仍使用自己的上游服务和模型配置，本配置不会自动同步到它。Widget沙箱、课内测验与PBL文字成果可使用，但不代替正式考试或人工训练评价。

## 请求失败与恢复

- 供应商401/403：检查模型密钥及模型使用权限。业务接口返回502，不将供应商认证失败当作管理员登录失效。
- 供应商429：检查调用额度或频率，稍后手动重试。不会自动重复调用模型。
- 供应商5xx：服务暂不可用，稍后手动重试。
- 无效或中断响应：暂停当前步骤；已保存场景和内容检查点保留。
- 超时：`AI_REQUEST_TIMEOUT_MS`默认90000毫秒，允许1000–180000。期限覆盖完整响应正文，持续缓慢返回不会无限延长。调整环境变量后需重启后端。

制课任务暂停后显示对应原因。修正配置前检查任务显示的模型；模型名称或服务地址改变时，旧任务不会混用新配置，需恢复原配置或新建任务。人工重试从检查点继续，生成结果仍需审阅后发布。供应商原始错误正文和密钥不回传页面。

自动化使用本地HTTP服务验证传输、故障、企业隔离和加密。用户指定模型的示范制课与单项输出有独立验收记录，不能据此保证其他模型、其他课程输出或所有媒体能力均可用。
