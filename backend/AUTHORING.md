# 本地 OpenMAIC 制课

已通过根 workspace 直接引用本仓库的 `@openmaic/dsl` 和 `@openmaic/generation` 源码包。生成提示词、内容/动作生成和课堂文档组装来自 OpenMAIC；模型适配、资料快照、企业权限、任务检查点及课程发布属于 Fastify 宿主。

## 使用路径

1. 管理员上传资料。在“AI 课堂能力 → 资料制课”对 PDF/DOCX/PPTX 点击“解析正文”；TXT/MD 上传时已有正文，可直接选择。
2. 保存并验证模型服务，刷新制课状态。选择本企业的学习课程草稿、资料和制课要求，提交大纲生成任务。
3. 大纲生成后查看任务，编辑标题、说明和知识点；保存修订后确认生成课堂。
4. 每个场景的内容与讲解动作分别调用模型，保留内容检查点。失败暂停，管理员确认重试；完整场景不重复生成。
5. 所有场景通过 DSL 校验后可应用到课程草稿。若草稿同时被修改或已发布，操作会拒绝，需刷新检查后重试。
6. 草稿中的完整课堂随课程发布冻结到 `course_versions`，原任务使用旧版本。

后台、大纲审阅、可视化编辑器、PC/H5播放器、进度与任务报告现已接入。示范企业已使用指定真实模型完成制课与学习闭环；每家企业仍须配置自己的模型并审阅生成内容。本轮复用H5，原生App宿主不在当前范围，完整试点放行以UX_AI_EXECUTION_PLAN.md的功能和视觉验收为准。

## API

所有管理接口前缀 `/api/tenants/:tenantId/`，需内容作者/企业管理员角色、会话及写入 CSRF。

| 方法与路径 | 用途 |
| --- | --- |
| POST `knowledge/:id/parse` | 解析本企业未归档资料，保存分段页码与错误 |
| GET `authoring/status` | 当前企业是否配置文本模型 |
| GET / POST `authoring/jobs` | 列表 / 创建任务，创建需 Idempotency-Key |
| GET `authoring/jobs/:id` | 大纲、场景、修订与事件 |
| PUT `authoring/jobs/:id/outline` | 携带 revision 更新大纲 |
| POST `authoring/jobs/:id/commands` | commandId、revision、action：confirm/retry/cancel/apply |

应用命令同时需 `courseUpdatedAt`。命令按 ID 去重，修订不匹配返回 409。后台单进程每次领取一个步骤，PostgreSQL 行锁和租约支持多实例互斥；租约过期的执行转暂停，不自动重复计费。取消后迟到响应不能覆盖状态。

## 资料和能力边界

- 正文解析支持 UTF-8 TXT/MD、DOCX 主正文、PPTX 幻灯片文字、PDF 文本层。图片、图表、版式与扫描件 OCR 不在本次文本解析能力内。
- 文件上传10MB；正文50万字符；PDF/Office最多500页，Office正文解压总量20MB；单制课任务最多20份资料、正文总量10万字符、大纲30个场景。
- 保存输入资料快照，原件归档后不继续新增课程关联；生成结果不自动发布。
- 资料中的指令仅作为资料内容处理。正式使用前必须审核模型输出；模型配置、资料范围与输出质量需要按企业和课程验收。
- 互动/PBL 场景沿用生成包契约；课内答题/反思运行态与互动沙箱已接入，完整Widget内部状态和多角色实时课堂仍需后续完成。模型端点暂只支持兼容 Chat Completions 的文本服务，非视觉资料解析。

## 验证证据

后端集成测试通过本地 HTTP 测试模型驱动真实 OpenMAIC 包：资料进入提示词 → 大纲修订 → 失败暂停 → 重试 → 生成场景和讲解动作 → 应用 → 发布快照 → 学习进度接口。另覆盖 DOCX/PPTX/PDF 正文提取、企业隔离和过期修订。

这是适配链路自动化证据，不是云模型输出质量、实际浏览器课堂学习或外部 App 宿主验收。生产依赖打包后，已单独验证 generation 提示词资源可加载；Docker 和外部 PostgreSQL 尚未实机运行。


## 讲解生成严格校验与重启恢复

2026-10-15：宿主后端在讲解动作调用处先用上游parseActionsFromStructuredOutput检查模型响应。无有效动作、空响应或未实际调用模型（例如提示词资源缺失）均暂停任务；不把上游按大纲生成的默认讲解当成模型生成成功。此限制放在Fastify宿主适配层，没有改写generation源码。

内容生成成功后已先保存pendingContent检查点；讲解失败时保留课件内容和完整场景，手动重试从讲解继续。集成测试实际通过本地HTTP模型返回无效文本，任务暂停且不可应用；重试只增加一次讲解请求，随后通过应用/发布/学习/报告检查。该服务为自动化fixture，不是用户配置的真实云模型。

另外在临时磁盘库模拟运行步骤租约过期，真正关闭HTTP应用和数据库、重新打开并注册后台任务；任务转paused、修订增加一次、内容检查点保留、租约清空，管理员可取消。恢复没有自动再次请求模型。最新后端26项测试及生产构建通过，日志.deploy/authoring-final-tests.log、.deploy/authoring-final-build.log。
