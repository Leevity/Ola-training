# ola-training · PC 管理端

独立的 React / TypeScript / Vite 管理端，风格继承移动端 STYLE-GUIDE。已接入 Fastify 业务后端，课程、任务、知识文件、组织成员和审计记录保存在服务端数据库，原文件保存于后端文件目录。

## 启动

先按照 [后端说明](../backend/README.md) 启动 4190 API，再在本目录执行：

```powershell
npm ci
npm run dev
```

打开 http://127.0.0.1:4180 。首次登录随机密码见 `backend/data/bootstrap-credentials.txt`。端口固定，若被占用会明确报错。开发服务仅绑定本机地址，代理 `/api` 至 4190。

```powershell
npm run build
npm run preview
npm test
```

测试使用 Node 的 TypeScript 类型擦除，建议 Node 22.19+ 或当前已验证的 Node 23.9。生产页面可静态托管，hash路由不需要服务端重写；子路径部署还需调整 base 与资源地址。

## 已实现

- 课程：学/训/考参数、课时内容、知识关联、搜索/筛选/分页、草稿、发布、预览、归档恢复。
- 任务：期限、课程选择/排序、部门/人员选择、发布与名单摘要、复制、详情、归档。
- 知识：真实原文件上传/下载、文本预览、分类、归档恢复。PDF/Word/PPT待解析。
- 成员与企业：添加/编辑、唯一编号、部门/角色、停用启用、账号开通、企业切换、部门维护、平台管理员开通企业。
- 登录、退出、会话恢复、服务端修订冲突反馈；AI 服务连接状态和生成任务操作。
- 报告：配置/分配统计、操作记录、成员和任务CSV导出。
- 表单校验、失败/空态反馈、弹窗键盘支持、响应布局。
