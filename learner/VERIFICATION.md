# PC 学员端验收

2026-10-15，Windows + Node.js，后端磁盘 PGlite，管理端 4180，学员端 4181。

## 已完成

- TypeScript 与 Vite 生产构建通过。
- 3 项前端领域测试：版本限定进度 / 重复课时、任务期限与固定版本、考试倒计时与视频协议。
- 后端扩展后 13 项集成测试通过；新增学员独立会话、收藏、完成后评价、会话幂等、同企业其他成员与跨企业会话隔离、通知已读和排行验证。
- 使用本地真实学员账号登录。完成“新客接待与需求识别”后任务从 0% 更新至 50%，下一阶段训练由锁定变为可开始。
- 收藏成功；课程评价提交并刷新后仍保留。站内消息全部已读后，未读数变为 0。
- 训练输入真实保存，结束后进入待评价；复盘显示原始表达，不显示模拟分数。
- 考试选择答案后自动保存；刷新恢复已答题目。完成单选、多选、填空，提交后服务端评分 100，成绩和作答回顾正确。
- 知识应用查询返回课程与“客户服务标准话术.md”原文。会话 URL 保存，刷新可恢复历史。
- 全局搜索能找到考试内容；无结果可重置。个人与部门排行读取真实学习记录。
- 默认桌面、1024 × 768 与 390 × 844 断点检查；已检查窄屏课程页没有横向溢出。窄屏视图不替代已有移动 H5。
- 浏览器运行错误日志检查无报错。开发格式化触发 Vite 重启时发生一次暂时断连，服务恢复后重载通过。
